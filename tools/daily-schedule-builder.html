Daily Schedule Builder Free — Weekly Planner Calendar

How to use

Click any date on the left calendar to open that day's planner. Click any empty time slot on the timeline to set the block's start time and open the add form. Drag blocks up or down to move them, or drag the bottom handle to resize. All changes save instantly to localStorage.

Monthly calendar view

Coloured dots below each date show which days have scheduled blocks. The dot colors match the blocks on that day. Navigate between months with the arrow buttons. Click Jump to today at any point to return to the current date.

Copy from another day

The sidebar lets you copy yesterday's schedule, last week's same day, or last Monday into the current day. Useful for recurring patterns without needing to recreate every block manually.

Recurring blocks

Set any block to repeat daily, on weekdays, or on the same day each week. Recurring blocks appear automatically on matching days with a repeat badge. Nothing leaves your device — all data stores locally in your browser.

Frequently Asked Questions

Does the daily schedule builder save my data automatically?

Yes. Every block you add, move, or resize saves instantly to your browser's localStorage. Close the tab, shut down your computer, come back tomorrow — your schedule is exactly where you left it. Nothing syncs to a server.

Can I plan multiple days at once?

Yes. Click any date on the left calendar to switch between days. Each day stores its own set of blocks independently. The coloured dots below each date show you at a glance which days already have something scheduled.

How do recurring blocks work?

When you create or edit a block, set it to repeat daily, on weekdays only, or on the same day each week. The block then appears automatically on every matching day with a repeat badge. You can still edit or delete individual instances without affecting the recurrence rule.

Can I copy a schedule from a previous day?

Yes. The sidebar copy tool lets you pull in yesterday's schedule, last week's same day, or last Monday. Select the source, hit copy, and all blocks transfer to the current day. You can then edit them freely without changing the original.

Is there a limit on how many blocks I can add?

No hard limit. localStorage can hold several megabytes of data, which translates to hundreds of blocks across many months. For most people planning a normal work day, storage is never a concern.

Does this work on mobile?

Yes. The layout adapts to smaller screens. On mobile, tap a time slot to add a block and use the edit button to adjust timing. Drag-to-resize works on touch screens that support pointer events.

Do I need to create an account?

No account, no sign-up, no email required. Open the page and start building your schedule immediately. Your data stays in your browser and never touches any external server.
